# Mobile Engineer

## Description

We are looking for a Mobile Engineer to build and maintain our customer-facing iOS and Android apps. You will design app features with product and design teams, keep the apps fast and stable, and work closely with backend engineers on the APIs the apps depend on.

## Responsibilities

- **Feature Delivery**: Build and ship features for iOS and Android with clean, tested code
- **App Architecture**: Maintain the app architecture and shared components used across features
- **Quality and Performance**: Reduce crashes and slow screens using profiling and monitoring data
- **Collaboration**: Agree API contracts with backend engineers and review designs with the product team
