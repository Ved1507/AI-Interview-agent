# Frontend Engineer

## Description

Join our frontend team to build responsive, accessible, and performant user interfaces for our web platform. You will collaborate with designers and backend engineers to create seamless user experiences while maintaining code quality and performance standards.

## Responsibilities

- **UI Implementation**: Build responsive and accessible UI components from design specifications
- **Performance Optimization**: Optimize bundle sizes, render performance, and Core Web Vitals
- **Code Quality**: Write clean, maintainable code with comprehensive test coverage
- **Design Collaboration**: Work closely with designers to ensure pixel-perfect implementation
