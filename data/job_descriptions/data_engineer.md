# Data Engineer

## Description

We are looking for a Data Engineer to build the pipelines and warehouse that our analysts and data scientists depend on. You will move data reliably from source systems into the warehouse, model it for analysis, and make sure the numbers can be trusted.

## Responsibilities

- **Pipeline Development**: Build and schedule batch and streaming pipelines that load data reliably
- **Data Modelling**: Design warehouse models that are clear, documented and fast to query
- **Data Quality**: Add tests, freshness checks and alerts so that broken data is caught early
- **Stakeholder Support**: Help analysts and data scientists get the data they need, and explain trade-offs
