# Cloud Architect

## Description

We are looking for a Cloud Architect to set the direction for our cloud platform. You will design the architecture for new systems, plan migrations, balance cost, security and reliability, and guide engineering teams to build on sound foundations.

## Responsibilities

- **Solution Design**: Design cloud architectures for new products, with clear trade-offs written down
- **Migration Planning**: Plan and sequence the move of existing systems to the cloud with minimal risk
- **Governance**: Set standards for networking, identity, security and cost across teams
- **Technical Leadership**: Review designs, mentor engineers and make decisions that others can follow
