# Machine Learning Engineer

## Description

We are looking for a Machine Learning Engineer to take models from research into production. You will build training and serving pipelines, deploy and monitor models at scale, and work with data scientists to turn prototypes into reliable services.

## Responsibilities

- **Model Deployment**: Package, deploy and version models so they can be served reliably
- **Training Pipelines**: Build reproducible training pipelines with tracked experiments and data
- **Model Monitoring**: Watch model quality, data drift and latency in production, and respond to problems
- **Engineering Practice**: Write production-grade code, with tests, reviews and documentation
