# QA Automation Engineer

## Description

We are looking for a QA Automation Engineer to make our releases faster and safer. You will design test strategies, build automated tests for web and API layers, and work with developers to find defects early in the development cycle.

## Responsibilities

- **Test Automation**: Build and maintain end-to-end and API test suites that run in the pipeline
- **Test Strategy**: Decide what to test automatically, what to test manually, and at which level
- **Defect Analysis**: Investigate failures, find root causes and report them clearly to developers
- **Quality Metrics**: Track flaky tests, coverage gaps and escaped defects, and act on them
