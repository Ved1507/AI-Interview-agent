# DevOps Engineer

## Description

We are looking for a DevOps Engineer to build and run the delivery pipelines and cloud infrastructure that our product teams rely on. You will automate deployments, operate Kubernetes clusters, and improve reliability through monitoring and incident response.

## Responsibilities

- **Pipeline Automation**: Build and maintain CI/CD pipelines that test and deploy services safely
- **Infrastructure as Code**: Define cloud resources with Terraform and review infrastructure changes with the team
- **Reliability**: Set up monitoring, alerting and dashboards, and reduce alert noise over time
- **Incident Response**: Take part in on-call rotations and lead post-incident reviews
