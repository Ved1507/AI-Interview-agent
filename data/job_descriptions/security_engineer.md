# Security Engineer

## Description

We are looking for a Security Engineer to protect our products and cloud environment. You will review designs and code for security issues, manage vulnerabilities, set up secure access controls, and help product teams build security in from the start.

## Responsibilities

- **Application Security**: Run threat models and secure code reviews for new features
- **Cloud Security**: Set and review identity, network and key-management controls in the cloud
- **Vulnerability Management**: Triage and track security findings through to a fix
- **Security Operations**: Monitor alerts, lead security incident response and write clear reports

- Container and Kubernetes security
